# Vaultwright

Vaultwright is a local-first maintenance layer for Obsidian vaults. It should help Codex inspect the vault while keeping actual changes under user control.

## Goals

- Read Markdown safely
- Extract tasks, tags, links, headings, and frontmatter
- Create new review and proposal notes only

## Non-goals

- No Obsidian UI in v0.1
- No ChatGPT App in v0.1
- No automatic patch application
