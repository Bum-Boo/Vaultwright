# Roadmap

## v0.1

- Local STDIO MCP server
- Safe vault scanning and note reading
- Markdown metadata extraction
- Task extraction
- Conservative link opportunities
- New Vaultwright-owned review, proposal, and patch proposal notes

Vaultwright v0.1 never modifies existing user notes. Codex performs the reasoning, while the MCP server only performs deterministic local file operations.

## Later

- User-approved patch application
- Optional Obsidian UI plugin
- Richer reports and dashboards
